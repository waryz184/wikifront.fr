# Démontage des pare-chocs (Frontera A)

Tuto pour le retrait des pare-chocs avant et arrière sur Opel Frontera A (1991-1998).

## Pare-chocs avant
Par le dessous de la voiture, dévissez quatre boulons qui fixent les supports du pare-choc aux longerons. 

*⚠️ Attention : Le risque de casser les boulons est très élevé. Il est essentiel d'appliquer un lubrifiant pénétrant (type WD40) avant l'opération.*

Notez que les écrous sont soudés aux longerons, il n'est donc pas nécessaire de les maintenir.

![Emplacements de montage avant](https://remont-bampera.com/images/opel/0_Opel_Frontera_A_1.jpg)
![Schéma de montage avant](https://remont-bampera.com/images/opel/0_Opel_Frontera_A_2.jpg)

## Pare-chocs arrière
Pour retirer le pare-choc arrière, dévissez quatre boulons qui fixent les supports du pare-choc aux longerons. 

*⚠️ Attention : Ces boulons sont souvent sujets à la corrosion. Appliquez un lubrifiant pénétrant pour minimiser le risque de casser le filetage ou le boulon lui-même.*

Là encore, les écrous sont soudés aux longerons, il n'est donc pas nécessaire de les fixer ou de les maintenir.
