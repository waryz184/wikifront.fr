# Bienvenue sur Frontopedia 🚗

Bienvenue sur le wiki de ma voiture. Ici je centralise tout ce qui concerne :

- **L'entretien** : vidange, pneus, freins, vidanges...
- **Les spécifications** : moteur, dimensions, capacités...
- **Les modifications** : upgrades, changements...

## Organisation

Les pages sont écrites en Markdown. Pour ajouter ou modifier une page :

1. Clone le repo
2. Édite / ajoute un fichier `.md` dans `docs/`
3. Ouvre une Pull Request
4. Une fois mergée, le déploiement est automatique ✨

## Build & preview en local

```bash
# Installer MkDocs
pip install mkdocs mkdocs-material

# Preview
mkdocs serve

# Build statique
mkdocs build
```
