# Vidange

## Huile moteur

| Spécification | Valeur |
|---------------|--------|
| Huile recommandée | 5W-30 (norme ACEA C2) |
| Quantité | 4,5 L |
| Filtre à huile | Réf. OEM 12345 |

## Fréquence

Tous les **15 000 km** ou **1 an** (au premier des deux termes).

## Procédure

1. Vidanger l'huile à chaud (moteur tiède)
2. Remplacer le joint de vidange (25 Nm)
3. Remplacer le filtre à huile
4. Remplir avec 4,5 L d'huile
5. Contrôler le niveau
