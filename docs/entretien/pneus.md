# Pneus

## Dimensions

| Position | Taille | Pression |
|----------|--------|----------|
| Avant | 205/55 R16 | 2,3 bar |
| Arrière | 205/55 R16 | 2,1 bar |

## Types de pneus

- **Été** : Michelin Primacy 4+ (usure douce, bonne tenue pluie)
- **Hiver** : Michelin Alpin 6 (obligatoires sous 7°C)

## Usure

Seuil légal : **1,6 mm** de profondeur. Remplacer recommandé à **3 mm**.

## Permutation

Permuter avant/arrière tous les **10 000 km** pour user les 4 pneus uniformément.
