# Démontage des pare-chocs (Frontera B)

Tuto pour le retrait des pare-chocs avant et arrière sur Opel Frontera B (1998-2004).

## Outils nécessaires
- Jeu de clés à douille.
- Une barre d'extension robuste et longue.
- Tournevis plat et cruciforme.
- Lubrifiant pénétrant (type WD40).

## Pare-chocs avant

1. **Grille de protection** : Si installée, dévissez les quatre boulons par le dessous et retirez la grille.
2. **Connexions** : Déconnectez les tuyaux du système de lavage des phares et les connecteurs des feux de brouillard.
3. **Passages de roue** : Dévissez un boulon de chaque côté qui fixe les pare-boue.
4. **Fixations châssis** : Par le dessous, dévissez deux boulons de 17 mm de chaque côté fixant les supports aux longerons. 
   *⚠️ Attention : les boulons peuvent casser, utilisez du lubrifiant pénétrant.*

## Pare-chocs arrière

1. **Passages de roue** : Dévissez les vis, retirez les clips et enlevez les pare-boue.
2. **Supports** : Derrière les pare-boue, dévissez deux écrous de chaque côté et retirez les supports métalliques courbés.
3. **Électricité** : Passez sous la voiture et déconnectez les connecteurs électriques.
4. **Fixations châssis** : Par le dessous, dévissez deux boulons de chaque côté fixant les supports aux longerons. (Une clé à douille avec extension longue est indispensable).
5. **Retrait** : Avec l'aide d'un assistant, retirez uniformément les supports des longerons.
